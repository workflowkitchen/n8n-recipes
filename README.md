# n8n Recipes by Workflow Kitchen

Copy-paste n8n automations for small business. Every recipe comes with a video walkthrough on [YouTube](https://www.youtube.com/@workflowkitchen), an importable `workflow.json` and a setup guide. Free, no email.

| # | Recipe | What it does |
|---|---|---|
| 001 | [Instagram Comment → DM](001-instagram-comment-to-dm/) | Auto-DMs everyone who comments your keyword, replies publicly, logs the lead in Google Sheets |

**How to import:** n8n → Workflows → Import from file → pick the recipe's `workflow.json`. Credentials are never included: add your own.
