# n8n Recipes by Workflow Kitchen

Copy-paste automations for small business: n8n workflows and Claude Code recipes. Every recipe comes with a video walkthrough on [YouTube](https://www.youtube.com/@workflowkitchen), the files to copy and a setup guide. Free, no email.

| # | Recipe | What it does |
|---|---|---|
| 001 | [Instagram Comment → DM](001-instagram-comment-to-dm/) | Auto-DMs everyone who comments your keyword, replies publicly, logs the lead in Google Sheets |
| 002 | [Claude Code Lead Generation](002-claude-code-lead-generation/) | `/find-leads dentists Austin TX`: local businesses from OpenStreetMap, emails from their own sites, MX-checked CSV for Instantly. $0 data |

**How to use:** n8n recipes → n8n → Workflows → Import from file → `workflow.json`. Claude Code recipes → copy the folder, `cd` into it, run `claude`. Credentials are never included: add your own.
